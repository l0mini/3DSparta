# 🔥3D Jump Map (Unity)

이 프로젝트는 Unity로 제작한 **작은 규모의 3D 점프맵**입니다. 플레이어는 점프대와 움직이는 플랫폼을 활용해 장애물을 피해 도달 지점까지 이동해야 합니다.  
IsTrigger와 TryGetComponent를 이용하여 플레이어를 감지하고 데미지를 주는 **불 장애물**이 포함되어 있습니다.

## 🎮 주요 기능

- **점프대**
  플레이어가 닿으면 위로 튀어 오르는 기능을 제공하는 오브젝트입니다.  
  Rigidbody에 순간적인 힘(Impulse)을 적용하여 구현하였습니다.

- **움직이는 플랫폼**
  일정한 경로를 따라 반복적으로 움직이며, 플레이어가 위에 탑승해 함께 이동할 수 있습니다.
  Sin을 사용하였고 움직이는 거리와 속도를 조절할 수 있습니다.

- **불 장애물** 
  TryGetComponent를 사용해 플레이어를 감지하고 일정시간마다 데미지를 주도록 InvokeRepeating을 사용하였습니다.

- **레이어 기반 감지 시스템**  
  플레이어만 데미지를 받도록, Unity의 **LayerMask**를 활용하여 충돌 감지를 제한합니다.

- **간단한 데미지 시스템**  
  불 장애물에 닿으면 UI에 플레이어의 체력이 줄어들고 화면이 잠시 빨게지는 연출을 하였습니다.

- **스태미나 시스템**
  점프시에 스태미나가 줄어들어 점프맵 진행시 점프 횟수에 제약을 주었고 시간의 흐름에 따라 회복하도록 하였습니다.

-**인벤토리 시스템**
  소비아이템인 당근을 주울 수 있고 당근을 먹을 시 체력과 스태미나가 회복되게 하였습니다.
  장착 아이템을 획득하고 선택했을 경우 사용하기 버튼이 아닌 장착과 해제버튼이 나오게 하였습니다.
  장착과 해제는 현재 구현중에 있습니다.

## 🧱 사용 기술

- Unity 2022 이상
- C# 스크립팅
- Rigidbody 물리 연산
- Trigger / TryGetComponent
- Transform 이동 및 반복 애니메이션
- 기본 UI 체력 표시
